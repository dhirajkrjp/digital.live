Pet Projects

See my up-to-date projects on my GitHub.

M2: AI Memory System is a centralized knowledge system powered by embeddings and FAISS. It enables semantic search across tasks, meetings, and PDFs with AI-driven summarization, task generation, and multi-user support via Streamlit. Think of it as a second brain for knowledge workers.
Duper AIO is a robust personal management ecosystem for productivity, finance, and security. Features gesture-driven UI, secure encrypted storage for private notes, and a modular architecture built for performance. Built with React Native and Expo.
Geometry of a Nightingale Song is a research analysis of nightingale vocalizations using geometric and topological data analysis (TDA). Transforms audio into point clouds and manifolds, visualizing structure, motifs, and variability using dimensionality reduction techniques. Related: see the full research writeup on GitHub.
Reddit Search Application is a powerful multi-modal discovery tool for the Reddit ecosystem. Provides a streamlined, dark-themed interface categorizing results into text, high-resolution images, and curated video feeds using the Reddit API.
